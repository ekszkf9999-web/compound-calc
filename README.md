# 포트폴리오 복리 계산기

예금과 주식(ETF·개별 종목)을 **항목별로 나눠 입력하고, 복리로 합산**해서 보여주는 모바일 웹 앱(PWA)입니다.
항목은 언제든 추가·수정·삭제할 수 있고, 모든 입력값은 그 기기 브라우저(localStorage)에만 저장됩니다.

- 앱 셸: `index.html` · `styles.css` · `app.js`
- 오프라인 실행: `manifest.webmanifest` · `sw.js` · `icon-192.png` · `icon-512.png`
- 배포용: `.nojekyll` (GitHub Pages에서 `_` 로 시작하는 파일도 그대로 서비스)
- 단일 파일 빌드: `python3 build_standalone.py` → `../../downloads/복리-계산기-앱.html`

## 실행

```bash
# 폴더 안에서 정적 서버 실행
python3 -m http.server 8000
# 폰/PC 브라우저에서 http://localhost:8000 접속
```

휴대폰에서는 브라우저 메뉴의 **홈 화면에 추가**로 설치하면 주소창 없이 실행되고, 한 번 열어 두면 오프라인에서도 동작합니다.

## GitHub Pages 배포 (선택)

1. 이 폴더의 파일을 공개 저장소 루트(또는 `docs/`)에 그대로 올립니다.
2. 저장소 Settings → Pages → Branch: `main` / 폴더 선택 → Save.
3. `https://<사용자>.github.io/<저장소>/` 로 접속합니다.

이 앱은 **네트워크 요청이나 외부 CDN을 전혀 쓰지 않습니다.** 개인정보(실명·생년월일·계좌 등)는 코드에 넣지 않았고,
사용자가 입력한 금액도 서버로 전송되지 않습니다.

## 기능

### 1) 내 포트폴리오 (항목별 설정)
- 기본 프리셋 4개: `예금 / 적금`(연 3.2%, 일반과세 15.4%), `나스닥 100`(11.0%), `S&P 500`(9.5%), `미국 배당 다우존스`(8.0%)
- **＋ 새 항목 추가**로 개별 종목·국내주식·채권·CMA 등 원하는 항목을 계속 추가 (최대 12개)
- 항목마다 이름, 구분(예금/주식/기타), 현재 보유금, 월 적립금, 예상 연 수익률,
  복리 방식(월복리/연복리), 과세 방식(비과세/과세이연/일반과세 15.4%)을 수정
- 만원/억원 빠른 입력 버튼(+100만 · +1,000만 · +1억), 수익률 슬라이더
- 항목별 스위치로 계산에서 빼기(비활성), 휴지통 없이 즉시 삭제(확인 후)

### 2) 통합 복리 계산
- 기간 1~50년 슬라이더 + 직접 입력, 물가상승률 반영(실질 가치) 선택
- **전체 합산 카드**: 최종 예상 자산, 총 투자 원금, 순수 복리 수익, 원금 대비 배수, 가중평균 연 수익률
- **예금 vs 주식 비중**과 항목별 최종 금액·수익금 비교
- **SVG 차트**: `원금 vs 수익` / `항목별 누적` 전환, 막대를 누르면 그 연도의 상세 금액
- **목표 마일스톤**: 1억·5억·10억·30억·60억 기본 + 직접 추가. 70년까지 계산해 도달 연차를 표시
- **연도별 상세 표**: 연차·연도·원금·복리 수익·총자산, 항목별 필터

### 3) 목표 역산
- 목표 금액·기간·예상 수익률을 넣으면 **필요한 월 적립금**을 계산 (현재 보유금 포함 여부 선택)
- 그 월 납입액을 **현재 항목 비중대로 배분한 항목별 월 납입액**과, 항목별 수익률을 적용한 예상 최종 금액

### 4) 시나리오 저장·비교
- 지금 구성을 이름 붙여 최대 5개 저장, 불러오기·삭제
- 두 개를 골라 최종 자산·원금·수익·배수·수익률·항목별 금액을 나란히 비교

## 계산 방식

| 항목 | 처리 |
| --- | --- |
| 납입 | 매월 말 적립 (기말 납입) |
| 월복리 | 월 이율 = 연이율 ÷ 12, 매월 잔액에 적용 |
| 연복리 | 연 1회 잔액에 적용, 그해 적립금은 연말에 더함(그해 이자 없음) |
| 과세 | 일반과세 15.4%는 **수익금에 대해 만기 일시** 적용, 비과세·과세이연은 세전 금액 표시 |
| 합산 | 항목별 세후 금액을 단순 합산 |
| 물가 | 실질 가치 = 최종 자산 ÷ (1 + 물가상승률)^기간 |
| 가중평균 수익률 | 각 항목 수익률을 **총 납입 원금 비중**으로 가중 |

세금·수익률은 단순화한 추정치이며 투자 권유가 아닙니다.

## 개인정보

- 입력값은 브라우저 `localStorage`(키 `compoundCalc.v1`)에만 저장되고 전송되지 않습니다.
- 생년월일·실명·연락처 등 개인 식별 정보를 코드에 넣지 않았습니다.
- 저장이 막힌 환경(일부 브라우저의 `file://` 실행, 시크릿 모드)에서는 자동 저장 없이 그 세션 동안만 동작합니다.

```bash
python3 build_standalone.py
# → ../../downloads/복리-계산기-앱.html (CSS·JS 인라인, 외부 요청 0건)
```

이 파일은 그대로 메신저로 보내 폰에서 열어도 됩니다. (PWA 설치·오프라인 캐시는 폴더 배포본에서만 동작)

```bash

```

수익률 슬라이더, 탭 전환, 차트 두 모드와 막대 터치, 연도별 표 필터, 목표 추가·삭제, 역산 공식,
시나리오 저장·비교, localStorage 유지, 서비스 워커·캐시·manifest, 다크 모드, 콘솔 오류 0건,
외부 네트워크 요청 0건, 가로 스크롤 0건, 기간 50년·항목 0개·저장값 손상 같은 경계 조건.
